#Customer Support AI System

This project implements an AI-based chatbot designed to assist banking customers by answering common questions and providing support. It uses natural language processing to understand user queries and generate relevant responses, improving customer service efficiency.

#Key Features:

- AI chatbot for customer support

- Natural language understanding of user queries

- Predefined responses for common banking questions

#Technologies:
Python, NLTK, Scikit-learn, Pandas

#Business Impact:

- Reduces workload on customer support teams

- Provides instant responses to customers

- Enhances overall customer experience
